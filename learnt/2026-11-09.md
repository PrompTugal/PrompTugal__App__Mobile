# What each app learnt: 9 November 2026

## Android (RiskMandate, conductor.android)
- First on-device chat: build 0.1.78, Lenovo Idea Tab Plus, Gemma 4 E2B (`.litertlm`) on LiteRT-LM: about 5.4 to 5.5 tokens/s decode (68 tokens in 13.6 s; 140 in 26.5 s).
- Dinis's tablet findings, fixed: a short verbatim riskmandate.ai system block on every request; the "Runs on this device" badge (pt-PT "Funciona neste dispositivo"); markdown bold markers stripped; chat sampling temperature 0.4, top-p 0.9.
- ABP Lab: 5 synthetic scenarios, one policy engine in Python and Kotlin, 54 shared golden vectors.
- Next: the Workbench (run, sweeps, ~20 tool-calling tests; native tool calls vs a JSON text protocol).

## iOS (team app, conductor@web-summit.dinis)
- LLM is cloud only today: PTAsk over OpenRouter (Sonnet default), user's own key in the Keychain, read-only tools (`now`, `search_agenda`, `my_picks`, `team_status`, `my_agents`, `where_is_everyone`), context as `<context>` blocks marked as data.
- No on-device model yet; RiskMandate on iOS is a placeholder. Next: M-iPad (LiteRT-LM Gemma 4, Apple Foundation Models, maybe MLX).

## Shared, or to share
- The same base system block and the same scenarios on both, so the speed and eval figures compare.
- iOS's bridge envelope (`window.ptApp`) as the shared bridge; Android's eval formats and ABP vectors as the shared evals.
